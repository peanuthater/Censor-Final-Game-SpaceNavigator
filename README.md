# Space Navigator — Embedded Reaction Game (Censor Final Project)

## Overview
This project implements a 90s-style handheld electronic reaction game 
using the Xiao ESP32-C3 and CircuitPython.

## Game Features
- 3 difficulty modes
- 10 levels per difficulty
- Increasing number of actions each level
- Accelerometer and rotary encoder based actions
- OLED display interface
- NeoPixel feedback
- Game Over / Win screens
- Restart without power cycling
